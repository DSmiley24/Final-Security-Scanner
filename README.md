# Final-Security-Scanner

This script is simply a basic file/directory scanner. It scans these files and determines if there are any secrets
or informatuon that could be exposed.

You make it function by typing in the file path while using the command line to run the code. So if you type something
like:

  - python scanner.py /path/to/folder/file
  - python scanner.py /this/is/an/example

Then it'll scan the directory of your choice. However, if you simply hit that run button in the rop right hand corner of Visual Studio, it'll scan the directory the scanner.py file is in. It's simple, I could have done more,
